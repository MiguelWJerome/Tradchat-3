Welcome, engineering recruiters and hiring managers! You are currently viewing the live portfolio demonstration instance of TradChat 3.

🚀 Breaking the Fourth Wall: Why This Instance Exists

TradChat was originally designed from scratch as an authentic, private real-time communication platform for a traditional faith-based community and close circle of friends. Because the production version houses personal conversations and user safety data, this showcase environment was specifically prepared to let engineering teams test drive the codebase safely.

All databases, accounts, messages, and administrative audit logs in this instance have been sanitized and pre-populated with deterministic test fixtures (Alex, Sam, Jordan, and Admin) so you can evaluate the platform's architectural capabilities firsthand.

🛠️ Core Engineering Highlights to Explore

  • ⚡ Low-Latency WebSockets: Experience bi-directional event dispatching and room state synchronization powered by Flask-SocketIO and eventlet concurrency.
  • 🎨 Dynamic Theming Engine: Navigate to Settings → Theme to test runtime CSS token injection (switch between High-Mass, Umbria, Consecration, Classic, and Coding modes).
  • 🛡️ Granular Safety & Parental Controls: Inspect the automated curfew time lock scheduler, content filters, and direct message permissions.
  • 📊 Role-Based Admin Operations: Visit the Admin panel to view real-time alert queues, user freeze/unfreeze workflows, and room scan audits.
  • 💾 Thread-Safe Persistence: Inspect SQLite connection pool management with parameterized queries protecting against SQL injection.
